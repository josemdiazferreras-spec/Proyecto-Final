🖧 Proyecto de Redes: VLAN + HSRP + DHCP + Seguridad
📌 Descripción

Este proyecto implementa una topología de red empresarial que integra segmentación mediante VLANs, alta disponibilidad con HSRP, asignación automática de direcciones IP (DHCP), enrutamiento estático, agregación de enlaces (LACP) y seguridad en switches.

La red está diseñada para garantizar conectividad total, redundancia y administración eficiente de usuarios y servicios.

🗺️ Topología de Red

La red se divide en dos segmentos principales:

🔹 Red de Usuarios
Routers: R1 y R4
Switches: SW1 (principal) y SW2 (acceso)
VLANs:
VLAN 300 → Estudiantes
VLAN 500 → Académicos
VLAN 999 → Administrativa
Protocolo HSRP para alta disponibilidad:
R4 → Router activo
R1 → Router de respaldo
🔹 Red de Servicios
Router R3:
Servidor DHCP
DNS / WEB
Dispositivos:
Switch de acceso
Controlador inalámbrico (WLC)
Puntos de acceso (APs)
Laptops
🔹 Core de la Red
Router R2:
Interconecta todos los routers
Permite comunicación entre redes

SSH (Acceso remoto seguro)
