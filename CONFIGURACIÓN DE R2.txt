CONFIGURACIÓN DE R2 

enable
Accede al modo privilegiado.

conf t
Entra al modo de configuración global.

hostname R2-C
Asigna el nombre al router.

ip domain-name iltla.edu.do
Define el dominio necesario para SSH.

crypto key generate rsa general-key
Genera las claves RSA para cifrado.

ip ssh version 2
Activa SSH versión 2.

username 20250693 secret Fe2024
Crea usuario local.

username opelegrino secret Fe2024
Crea segundo usuario.

line vty 0 4
Accede a líneas remotas.

login local
Usa usuarios locales para autenticación.

transport input ssh
Permite solo SSH.

exit
Sale de configuración VTY.

interface GigabitEthernet0/1
Selecciona interfaz hacia R1.

ip address 192.168.100.2 255.255.255.252
Asigna IP del enlace.

no shutdown
Activa la interfaz.

exit
Sale de la interfaz.

interface Serial0/0/0
Selecciona enlace hacia R4.

ip address 192.168.100.10 255.255.255.252
Asigna IP.

no shutdown
Activa interfaz.

exit
Sale de la interfaz.

interface Serial0/0/1
Selecciona enlace hacia R3.

ip address 192.168.100.6 255.255.255.252
Asigna IP.

no shutdown
Activa interfaz.

exit
Sale.

ip route 192.168.32.0 255.255.255.0 192.168.100.5
Ruta hacia red LAN (R3).

ip route 192.168.30.0 255.255.255.0 192.168.100.1
Ruta hacia VLAN 300.

ip route 192.168.50.0 255.255.255.0 192.168.100.1
Ruta hacia VLAN 500.

ip route 192.168.99.0 255.255.255.0 192.168.100.1
Ruta hacia VLAN 999.

ip route 192.168.100.4 255.255.255.252 192.168.100.5
Ruta hacia red WAN.

ip route 192.168.100.8 255.255.255.252 192.168.100.9
Ruta hacia otra red WAN.

end
Sale de configuración.

wr
Guarda cambios.
